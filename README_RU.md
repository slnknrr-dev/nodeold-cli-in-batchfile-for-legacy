# nodeold

[English version](README.md)

Однофайловый batch-лаунчер старых версий Node.js для Windows.
Положите `nodeold.cmd` рядом со старым кодом и запустите. Нужный Node.js скачается при первом запуске: без установщика, без прав администратора и без изменений в системе.

```bat
nodeold app.js
```

При первом запуске скачается Node.js 5.12.0 (x86), распакуется в `C:\ProgramData\nodeold.cli\5x86`, и запустится `app.js`. Дальше Node.js стартует сразу.

Удобно для быстрой проверки или запуска старого кода и для автоматической установки на старых машинах.

## Имена

Версия выбирается по **имени файла**. Скопируйте или переименуйте `nodeold.cmd`:

```
node[<v>[x<arch>]|old[<bits>]][-<util>].cmd
```

| Часть | Значения | Что значит |
|---|---|---|
| `<v>` | `wxp` | Node.js 5.12.0, последняя для Windows XP |
| | `w7` | Node.js 13.14.0, последняя для Windows 7 |
| | `w8` | Node.js 18.20.8, последняя для Windows 8.1 |
| | `<n>` | последняя Node.js `<n>.x`, `n >= 4` |
| `x<arch>` | `x64`, `x86` | разрядность; по умолчанию — как у системы |
| `old[<bits>]` | `old`, `old32`, `old64` | Node.js 5.12.0, **по умолчанию x86** |
| *(ничего)* | `node` | самая новая уже установленная версия, см. ниже |
| `-<util>` | любая | запустить утилиту вместо `node` (см. ниже) |

Просто `node.cmd` (а также `node-npm.cmd`, `node-<util>.cmd`) ничего не скачивает: он запускает самую новую major-версию, которая уже есть в `NODEOLD_HOME`, с разрядностью системы (или `NODEOLD_ARCH`). Например, если на 64-битной системе установлены `5x86`, `13x86` и `21x64`, `node` запустит 21, а с `NODEOLD_ARCH=x86` — 13. Если подходящей версии нет, будет ошибка.

Примеры:

| Имя файла | Что запускает |
|---|---|
| `nodeold.cmd` | Node.js 5.12.0 x86 |
| `node.cmd` | самая новая установленная версия, разрядность системы |
| `nodeold64.cmd` | Node.js 5.12.0 x64 |
| `nodewxp.cmd` | Node.js 5.12.0, разрядность системы |
| `nodew7.cmd`, `nodew7x86.cmd` | Node.js 13.14.0, разрядность системы / x86 |
| `nodew8.cmd` | Node.js 18.20.8 |
| `node16.cmd`, `node22x64.cmd` | последняя 16.x / 22.x x64 |
| `nodew7-npm.cmd` | npm из Node.js 13.14.0 |
| `node16-eslint.cmd` | `eslint` из `node_modules\.bin` на Node.js 16 |

Для `node<n>` точная версия при установке берётся из `latest-v<n>.x/SHASUMS256.txt` на зеркале. Версии 5, 13 и 18 — финальные релизы, они зафиксированы.

## Утилиты: `-<util>`

```bat
nodew7-npm install
nodew7-eslint src
nodeold-gulp build
```

- `<util>` ищется так же, как Node.js ищет модули: `node_modules\.bin\<util>.cmd` (или `.bat`) в текущей папке, затем в каждой родительской, затем в папке Node.js.
- Исключение — `npm`: `-npm` всегда запускает npm, который идёт в комплекте с этим Node.js.
- Папка выбранного Node.js ставится первой в `PATH`, поэтому утилиты и дочерние процессы используют тот же `node`.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `NODEOLD_HOME` | `C:\ProgramData\nodeold.cli` | Где хранятся версии Node.js |
| `NODEOLD_MIRROR` | `https://nodejs.org/dist` | Зеркало для скачивания, структура как у nodejs.org/dist |
| `NODEOLD_ARCH` | — | `x86` или `x64`, если разрядность не указана в имени файла |

Приоритет разрядности: имя файла, затем `NODEOLD_ARCH`, затем x86 для `old`, затем разрядность системы.

## Как работает

1. Ищет `%NODEOLD_HOME%\<major><arch>\node.exe`, например `5x86` или `13x64`.
2. Если его нет, скачивает `node-v<version>-<arch>.msi` через `curl`, а если `curl` нет или он не сработал — через `bitsadmin`.
3. Распаковывает `.msi` через `msiexec /a` (административная распаковка). Ничего не устанавливается и не регистрируется.
4. Запускает `node.exe` (или утилиту) со всеми аргументами и возвращает её код выхода.

Используются только встроенные возможности `cmd` и средства Windows, поэтому работает начиная с Windows XP.

## Примечания

- **Windows XP / Windows 7 и HTTPS.** nodejs.org требует TLS 1.2. На XP его нет, на Windows 7 он есть только с обновлениями. Если скачивание не удалось, укажите в `NODEOLD_MIRROR` зеркало по `http://` или положите файлы Node.js в `%NODEOLD_HOME%\<major><arch>` вручную.
- **`bitsadmin`** не входит в стандартную Windows XP (он есть в Support Tools). Там нужен `curl` или ручное скачивание.
- **Node.js 5 x64 на современной Windows.** На свежих сборках Windows 11 `node.exe` 5.12.0 x64 падает, как только начинает выполнять JavaScript (`0xC0000005`); `--help` и `-v` при этом работают. Сборка x86 работает, поэтому `nodeold` по умолчанию берёт x86.
- **Нет x86 для новых версий.** У Node.js 23 и новее нет 32-битных сборок для Windows, поэтому `node24x86` выдаст ошибку.
- Папки установки называются `5x86`, `13x64`, `18x64` и т. д. Удалите папку, чтобы скачать версию заново.
